#+title: 从这里开始使用 Emacs
#+startup: showall

* 第一件事：随时可以取消
按 =C-g= 取消当前操作。=C-= 是 Ctrl，=M-= 在 Windows 上通常是 Alt。
=C-x C-f= 表示依次按 Ctrl+X、Ctrl+F；=M-x= 输入命令名后按 Enter。

- =C-h t=：官方交互教程。可用 =C-u C-h t= 选择教程语言。
- =C-h k=：接着按一个键，查看它会做什么。
- =C-h f= / =C-h v=：查询函数 / 变量的说明。
- =C-c e=：打开主配置，从头按章节读。

* 文件、缓冲区和窗口
文件在磁盘上；缓冲区是正在编辑的内容；窗口是展示缓冲区的一块区域。
关闭缓冲区不会删除磁盘文件。

| 按键      | 操作                  |
|-----------+-----------------------|
| C-x C-f   | 打开或新建文件        |
| C-x C-s   | 保存                  |
| C-x b     | 切换缓冲区            |
| C-x k     | 关闭缓冲区            |
| C-/       | 撤销                  |
| C-SPC     | 设置选区起点，然后移动 |
| M-w / C-w | 复制 / 剪切选区       |
| C-y       | 粘贴                  |
| C-x 2 / 3 | 上下 / 左右分屏       |
| C-x o / 1 | 换窗口 / 只保留当前窗口 |

中文输入法可能占用 =C-SPC=；=C-@= 也是设置选区起点的原生命令。

* 搜索、补全和项目
=C-s= 是原生增量搜索。=M-s l= 显示当前缓冲区的匹配行，=M-s r= 搜索目录
或项目中的内容（需要 rg）。=C-x p f= 查找项目文件，=M-g i= 查找文件符号。
候选多时，试试输入几个词；Orderless 不要求这些词挨在一起。

=C-M-i= 调用当前位置补全，Corfu 显示候选。=RET= 确认，=C-g= 取消。
写笔记时不会自动弹出正文补全；=M-x= 的命令候选仍随输入显示。

* 练习 Org：先创建自己的普通文件
这份指南属于配置。请用 =C-x C-f= 在自己的笔记目录新建 =practice.org=，
复制下面几行进行练习。=C-c n= 会打开你的笔记目录。

代码块可以用来记录代码，阅读本指南无需执行它们。

* Jai 的最小工作流
项目用 =jacket.toml= 或 Git 标记根目录。打开 =.jai= 后，jai-mode 负责颜色
和缩进；Jacket 的 jailsp 经 Eglot 提供语言服务。

- =C-M-i= 补全，=M-.= 定义，=M-,= 返回，=M-?= 引用。
- =M-x eglot-rename= 重命名，=M-x eglot-code-actions= 代码操作。
- =M-x flymake-show-buffer-diagnostics= 查看问题。
- =M-x kickstart-jai-format-buffer= 手动格式化，=C-/= 可一次撤销。

#+begin_src jai
#import "Basic";

    print("Hello, world!\n");

#+end_src

Jacket 0.30.4 的 LSP 不负责格式化；专用命令调用同套 jaifmt。保存不会触发格式化。
工具缺失时先编辑和记笔记即可，再在 =local.el= 设置 =kickstart-jacket-directory=。

* 逐步修改配置
先读 =init.el= 的章节注释，每次只改一处并重启。
=local.el= 存放本机路径，=var/custom.el= 存放 Customize 界面生成的设置。
不需要理解所有包：先熟悉原生操作，再了解搜索和补全各自解决的问题。

Everforest 配色参考 Zed 的 Dark Soft (material)，主题直接保存在仓库内，离线也能加载。
